# ra-digital

Public repo for the Ra Digital live site. Serves via GitHub Pages.

- Live URL: https://ra-shipit.github.io/ra-digital/
- Deploy: push to `main`; Pages serves from the repo root.

Pass this repo to a build session as the target. Keep proprietary / private
material OUT of this repo (it is public). The migration kit lives separately in
the private `ra-shipit/ai` repo.
